## 💻 نیازمندی‌های VPS

### حداقل مشخصات
- **OS**: Ubuntu 20.04+ یا Debian 11+
- **RAM**: ۵۱۲ مگابایت (توصیه: ۱ گیگ)
- **CPU**: ۱ vCore کافیه
- **Storage**: ۲ گیگ
- **Node.js**: نسخه ۱۸ یا بالاتر (توصیه: ۲۰)

### پکیج‌های سیستمی
```bash
sudo apt update
sudo apt install -y curl git build-essential python3 screen
```

### نصب Node.js 20 (رسمی)
```bash
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt install -y nodejs
node -v   # باید v20.x چاپ کنه
npm -v
```

## 📦 نصب گام به گام

### ۱) آپلود فایل‌ها به VPS
```bash
# روی VPS خودت:
mkdir -p ~/pvp_hs_bot
cd ~/pvp_hs_bot

# فایل‌ها رو با scp یا sftp آپلود کن
# یا از zip که بهت دادم استفاده کن:
unzip pvp_hs_bot.zip -d ~/pvp_hs_bot
```

### ۲) نصب dependencies
```bash
cd ~/pvp_hs_bot
npm install
```

این کار پکیج‌های زیر رو نصب میکنه:
- `mineflayer` — کتابخانه اصلی بات
- `mineflayer-pathfinder` — راه‌یابی
- `minecraft-data` — دیتای بلاک‌ها و آیتم‌ها
- `vec3` — ریاضی سه‌بعدی

### ۳) بررسی config
```bash
nano config.json
```
مطمئن شو که این‌ها درسته:
- `account.username`: `pvp_HSbot`
- `account.password`: `AZHAN8585@#@#ABOL1234`
- `owner.name`: `pvp_HS`
- `owner.authPassword`: `AZHAN8585@#@#ABOL1234`

### ۴) اجرا (تست اول)
```bash
node index.js
```

اگه همه چی درست باشه، توی لاگ می‌بینی:
```
================================================================
 6b6t BOT STARTING
================================================================
[CONFIG] Server: alt.6b6t.org:25565
[CONFIG] Username: pvp_HSbot
...
```

### ۵) اجرا در پس‌زمینه (production)
با `screen`:
```bash
screen -S bot
node index.js
# برای detach: Ctrl+A سپس D
# برای برگشت: screen -r bot
```

یا با `pm2` (توصیه):
```bash
sudo npm install -g pm2
pm2 start index.js --name pvp-hs-bot
pm2 save
pm2 startup   # دستور برگشت رو کپی کن و اجرا کن
pm2 logs pvp-hs-bot
```

## 📖 راهنمای کامل کامندها

> ⚠ همه کامندها باید از طریق **`/msg pvp_HSbot <command>`** فرستاده بشن. توی چت پابلیک بی‌جواب می‌مونن.

### 🔐 احراز هویت

| کامند | توضیح |
|-------|-------|
| `!auth <رمز>` | احراز هویت. **هر بار که بات ری‌استارت میشه باید بزنی.** |

بعد از `!auth` موفق، ازت زبان می‌پرسه (`1` فارسی / `2` انگلیسی).

### 🎮 تغییر مود

| کامند | توضیح |
|-------|-------|
| `!mode 0` | مود غیرفعال. فقط کامندهای عمومی کار می‌کنن. |
| `!mode 1` | مود شالکر فارم. کامندهای `!farm ...` فعال می‌شن. |
| `!mode 2` | مود کیت. کامندهای `?kit pvp` و `!confirm` فعال می‌شن. |

### 📡 کامندهای عمومی (همه مودها)

| کامند | توضیح |
|-------|-------|
| `!tpa` | بات به `pvp_HS` درخواست تیپی می‌فرسته. |
| `!home` | اطراف رو دنبال تخت می‌گرده و respawn ست می‌کنه. |
| `!drop` | همه رو دراپ می‌کنه به‌جز: **ارمور، الیترا، گلدن‌اپل، توتم**. |
| `!stats` | آمار: پینگ، TPS، HP، غذا، Armor، Uptime — همه در `/msg`. |
| `!render <n>` | رندر دیستنس (بین ۲ تا ۳۲). |
| `!help` | راهنمای کامل. |

### 🏭 کامندهای Mode 1 (شالکر فارم)

| کامند | توضیح |
|-------|-------|
| `!farm start` | حلقه فارم رو شروع می‌کنه (اگه اسکن نکرده باشه، اول اسکن می‌کنه). |
| `!farm stop` | فارم رو متوقف می‌کنه. |
| `!farm status` | وضعیت فعلی + تعداد سیکل‌ها. |
| `!farm scan` | اسکن مجدد اطراف. |

### 🎒 کامندهای Mode 2 (کیت)

| کامند | توضیح |
|-------|-------|
| `?kit pvp` | بات کیت PvP رو از چست‌ها برمیداره، به `pvp_HS` تیپی میده، شالکرها رو دراپ می‌کنه. |
| `!confirm` | بعد از این که کیت رو گرفتی، این رو بزن تا بات `/kill` کنه. |

### 🤝 قبول کردن TPA

بات **خودکار** TPA رو **فقط** از `pvp_HS` قبول می‌کنه. تو کاری لازم نیست بکنی.

## 🏭 مود ۱: شالکر فارم (Mode 1)

### دستگاه چیه؟

دو دکمه + یک دیسپنسر + یک چست + محل ماین‌کارت.

- **دکمه ۱** (`buttonMinecart`): یه Chest Minecart جلوی دیسپنسر می‌ذاره.
- **دکمه ۲** (`buttonFireball`): دیسپنسر یه Fireball شلیک می‌کنه و ماین‌کارت‌چست منفجر می‌شه؛ شالکرها میفتن توی چست.

### چرخه بات

1. اگه توی اینونتوریش ماین‌کارت‌چست خالی بود، دراپش می‌کنه.
2. دکمه ۱ رو می‌زنه → ماین‌کارت جلو ظاهر میشه.
3. رو ماین‌کارت‌چست کلیک می‌کنه (بازش می‌کنه).
4. همه شالکرهای اینونتوری (هر رنگ و اسمی) رو می‌ریزه توش.
5. بسته می‌کنه، میره سراغ دکمه ۲.
6. دکمه ۲ رو می‌زنه → انفجار.
7. صبر برای افتادن شالکرها.
8. تکرار.

### اسکن خودکار

وقتی `!farm start` رو می‌زنی (یا `!farm scan`)، بات:

- ۱۶ بلاک اطراف رو اسکن می‌کنه.
- نزدیک‌ترین Chest و Dispenser رو پیدا می‌کنه.
- دو تا نزدیک‌ترین Button رو پیدا می‌کنه.
- دکمه‌ای که به دیسپنسر **نزدیک‌تره** = دکمه فایربال.
- دکمه دیگه = دکمه ماین‌کارت.
- نقشه رو در `config.json` ذخیره می‌کنه.
- در `/msg` یه گزارش می‌فرسته که تایید کنی درسته.

### شروع
```
/msg pvp_HSbot !mode 1
/msg pvp_HSbot !farm start
```

### توقف
```
/msg pvp_HSbot !farm stop
```

## 🎒 مود ۲: کیت (Mode 2)

### چیدمان مورد نیاز

دو چست نزدیک هم که این‌ها توش باشه:
- **شالکر گیر**: End Crystal, Netherite Armor, Golden/Enchanted Apple, Sword
- **شالکر توتم**: پر از Totem of Undying

### روند کار

وقتی از توی `/msg` بزنی `?kit pvp`:

1. بات چست‌های نزدیک (تا ۱۲ بلاک) رو اسکن می‌کنه.
2. توی هر چست، **NBT شالکرها** رو می‌خونه و شالکر گیر و شالکر توتم رو پیدا می‌کنه.
3. هر دو شالکر رو برمیداره.
4. به `pvp_HS` تیپی می‌فرسته (`/tpa`).
5. بعد از تلپورت، چک می‌کنه که مالک نزدیک باشه.
6. دو تا شالکر رو دراپ می‌کنه.
7. در `/msg` می‌گه: **"کیت آماده"**
8. منتظر می‌مونه تا تو `!confirm` بزنی.
9. بعد از `!confirm`، `/kill` می‌زنه.
10. بعد از respawn، آماده سیکل بعدیه.

### شروع
```
/msg pvp_HSbot !mode 2
/msg pvp_HSbot ?kit pvp
# ... بات میاد، کیت رو دراپ می‌کنه ...
# ... تو برش می‌داری ...
/msg pvp_HSbot !confirm
# بات /kill می‌زنه
```

## 🔧 عیب‌یابی

### ❓ بات بعد از پورتال هیچ کاری نمی‌کنه
- مطمئن شو در `/msg` `!auth <رمز>` رو زدی.
- بدون `!auth` بات جواب هیچ چیزی رو نمیده.

### ❓ اسکن فارم Chest/Dispenser پیدا نمی‌کنه
- بات باید توی محدوده ۱۶ بلاکی دستگاه باشه.
- `!home` بزن که برگرده به respawn، اگه دستگاه دور بود ببرش نزدیک.
- `!farm scan` رو دوباره بزن.

### ❓ NBT شالکر خونده نمیشه (کیت گیر یا توتم پیدا نمی‌کنه)
- در ورژن‌های خیلی جدید (۱.۲۰.۵+) ساختار NBT فرق کرده. کد هر دو ساختار قدیمی و جدید رو پشتیبانی می‌کنه ولی اگه سرور خیلی خاص بود ممکنه نیاز به تنظیم داشته باشه.
- در چست، شالکرها باید مستقیم داخل چست باشن (نه داخل شالکر تو شالکر).

### ❓ بات وقتی kick میشه دوباره نمی‌آد
- بعد از kick خودکار ۳۰ ثانیه صبر می‌کنه و دوباره متصل میشه. صبر داشته باش.
- توی لاگ ببین دلیل kick چی بوده.

### ❓ ارور "verification failed"
- IP تو باید whitelisted باشه توی 6b6t.
- توی VPS معمولا مشکلی نیست. اگه بود، VPN بزن.

### ❓ چت لیمت خورده
- کد خودش تشخیص میده و ۵ ثانیه صبر می‌کنه. نگران نباش.
