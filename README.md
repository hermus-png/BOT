# 🤖 pvp_HSbot - 6b6t.org Advanced Bot

بات ماینکرافت پیشرفته برای سرور **6b6t.org** با دو مود اصلی:
- **Mode 1**: Shulker Farm (دستگاه فایربال)
- **Mode 2**: Kit Giver

---

## 📁 ساختار فایل‌ها

```
pvp_hsbot/
├── index.js                 # فایل اصلی - راه‌اندازی بات
├── config.js                # تنظیمات (سرور، اکانت، اونر)
├── package.json             # پکیج‌ها
│
├── commands/                # کامندهای عمومی
│   ├── tpa.js               # !tpa و قبول تیپی

│   ├── stats.js             # !stats (پینگ، TPS، HP، …)
│   └── help.js              # !help
│
├── modes/                   # مودها
│   ├── shulkerFarm.js       # Mode 1 - دستگاه فایربال
│   └── kit.js               # Mode 2 - کیت دادن
│
├── utils/                   # ابزارها
│   ├── logger.js            # لاگ‌گیری
│   ├── storage.js           # ذخیره config.json
│   ├── security.js          # سیستم owner (اسم + UUID)
│   ├── msg.js               # ارسال /msg (فقط به owner)

```

## 🚀 نصب روی VPS (قدم به قدم)

### ۱) نصب Node.js (نسخه ۱۸ به بالا)

```bash
# روی Ubuntu / Debian
sudo apt update
sudo apt install -y curl
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt install -y nodejs

# چک نسخه
node -v   # باید v20.x نشون بده
npm -v
```

### ۲) آپلود پروژه روی VPS

```bash
# فرض میکنیم پوشه رو گذاشتی توی /root/pvp_hsbot
cd /root/pvp_hsbot
```

### ۳) نصب پکیج‌ها

```bash
npm install
```

پکیج‌های نصب‌شده:
- `mineflayer` (کتابخانه اصلی بات ماینکرافت)
- `mineflayer-pathfinder` (مسیریابی)
- `prismarine-block`, `vec3` (وابستگی‌ها)
- `minecraft-data` (خودکار با mineflayer نصب میشه)

### ۴) اجرای اولیه (تست)

```bash
node index.js
```

باید ببینی که:
- بات وصل میشه
- `/login` رو خودش میفرسته
- میره داخل Portal 1 → 10 ثانیه → Portal 2
- بعد پیام "BOT READY - COMMANDS ACTIVE" میاد

### ۵) اجرا با PM2 (پیشنهاد میشه - همیشه بالا)

```bash
# نصب PM2
sudo npm install -g pm2

# اجرا
pm2 start index.js --name pvp-hsbot

# دیدن لاگ زنده
pm2 logs pvp-hsbot

# ری‌استارت خودکار وقتی VPS ریبوت شد
pm2 startup
pm2 save
```

### دستورات مفید PM2:
```bash
pm2 status              # وضعیت
pm2 stop pvp-hsbot      # توقف
pm2 restart pvp-hsbot   # ری‌استارت
pm2 delete pvp-hsbot    # حذف
```

## 🎮 راهنمای کامندها

### ⚙️ عمومی
| کامند | توضیح |
|-------|-------|
| `!lang 1` / `!lang 2` | تغییر زبان (1=فارسی، 2=English) |
| `!help` | راهنمای کامل |
| `!stats` | آمار بات (پینگ، TPS، HP، آرمور، غذا، …) توی `/msg` |
| `!render <n>` | رندر دیستنس (بین ۲ تا ۳۲) |

### 🎯 تیپی و ریسپان
| کامند | توضیح |
|-------|-------|
| `!tpa` | بات به `pvp_HS` تیپی میده |
| `!home` | تخت رو توی ۱۶ بلاکی پیدا میکنه و ست میکنه |
| — | تیپی از `pvp_HS` خودکار قبول میشه |
| — | تیپی از بقیه خودکار رد میشه |

### 🎒 اینونتوری
| کامند | توضیح |
|-------|-------|
| `!drop` | همه چیو دراپ میکنه به‌جز: آرمور، الیترا، گلدن‌اپل، ۱ توتم |
| — | AutoTotem خودکار (توتم همیشه توی offhand) |

### 🎮 مودها
| کامند | توضیح |
|-------|-------|
| `!mode 0` | هیچ مود فعال نیست (فقط کامندهای عمومی) |
| `!mode 1` | مود Shulker Farm |
| `!mode 2` | مود Kit |

### 🏭 Mode 1 - Shulker Farm
| کامند | توضیح |
|-------|-------|
| `!scan` | اسکن ۱۶ بلاکی + شناسایی دکمه/دیسپنسر/چست/ماین‌کارت |
| `!start` | شروع سیکل خودکار |
| `!stop` | توقف مود |

**نحوه کار:**
1. بات ۱۶ بلاک اطراف رو اسکن میکنه
2. دکمه Loader و دکمه Fireball رو خودش تشخیص میده (از روی نزدیکی به دیسپنسرها و ماین‌کارت‌ها)
3. سیکل:
   - اگه ماین‌کارت چست توی اینونتوری بود → دراپش میکنه
   - دکمه Loader رو میزنه → دیسپنسر ماین‌کارت میذاره
   - روی ماین‌کارت راست‌کلیک میکنه → همه شالکرها رو میریزه داخلش
   - دکمه Fireball رو میزنه → فایربال شلیک میشه
   - تکرار تا وقتی شالکر توی اینونتوری هست

### 🎁 Mode 2 - Kit Giver
| کامند | توضیح |
|-------|-------|
| `?kit pvp` | شروع فرآیند کیت |
| `!confirm` | تایید `/kill` بعد از دراپ کیت |
| `!stop` | توقف مود |

**نحوه کار:**
1. بات چست‌های ۱۶ بلاکی رو باز میکنه
2. شالکرها رو از NBT چک میکنه (بدون باز کردن) → شالکر PvP kit پیدا میکنه (کریستال، آرمور نداریتی، سورد، گاپل)
3. شالکر توتم پیدا میکنه (پر از توتم)
4. به `pvp_HS` تیپی میده و منتظر accept میمونه
5. بعد از رسیدن، اسم owner رو نگاه میکنه
6. کیت رو دراپ میکنه
7. `/msg` میفرسته: "کیت آماده"
8. منتظر `!confirm` میمونه
9. بعد از confirm → `/kill` میزنه → میره روی ریسپان

## 🔐 امنیت

- فقط `pvp_HS` میتونه کامند بزنه
- اسم دقیق چک میشه (case-sensitive)
- **UUID اولین بار ذخیره میشه** و از اون به بعد چک UUID هم انجام میشه
- اگه یه پلیر دیگه اسمشو بذاره `pvp_HS`، بلاک میشه (UUID فرق داره)
- **همه پیام‌ها فقط توی `/msg` به Owner** میره - هیچی توی چت پابلیک منتشر نمیشه
- **مختصات هیچ‌وقت** توی پیام‌های Owner نیست

## 🎯 ویژگی‌های امنیتی و طبیعی بودن

- ⏱️ تاخیرهای طبیعی متغیر (350-900ms بین اکشن‌ها)
- 👁️ چرخش سر قبل از هر کلیک
- 💬 صف چت با کول‌داون (۲.۵ ثانیه) → لیمیت چت نمیخوره
- 🔄 Auto-reconnect بعد از kick یا disconnect
- 💾 ذخیره تنظیمات توی `config.json` (زبان، مود، رندر، UUID)
- 🛡️ AutoTotem همیشگی
- 📊 TPS tracker (به جای FPS چون بات FPS نداره)

## ⚠️ نکات مهم

1. **بخش ورود به سرور دست‌نخورده مونده** - همون کدی که فرستادی، فقط username/password عوض شد
2. **VPN لازم نیست** - سرور 6b6t با VPS مستقیم کار میکنه
3. **verify error** روی VPS اگه دیدی، عادی هست (سرور 6b6t با auth: offline کار میکنه)
4. **باگ لود چانک**: بات ۱۰ ثانیه بعد از هر transfer صبر میکنه که چانک‌ها لود شن، بعد شروع به کار میکنه
